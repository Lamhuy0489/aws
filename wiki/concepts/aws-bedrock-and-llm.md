# AWS Bedrock va Tich Hop Mo Hinh Ngon Ngu Lon

- Danh muc: AI-ML
- Ngay tao: 2026-09-18

## 1. Dinh nghia va muc dich
AWS Bedrock la dich vu duoc quan ly hoan toan (fully managed service) cung cap quyen truy cap cac mo hinh nen tang hang dau (Foundation Models nhu Claude, Llama, Titan, Mistral) qua mot API duy nhat, dong thoi tich hop cac tinh nang Knowledge Base, Agent va Guardrails danh cho doanh nghiep.

## 2. Dac diem ky thuat chinh
- Tinh rieng tu du lieu: Du lieu khach hang khong duoc dung de huan luyen lai mo hinh.
- Bedrock Knowledge Base: Tu dong hoa quy trinh chunking, embedding va vector storage vao OpenSearch Serverless.
- Bedrock Agents: Ho tro tao tac nhan thong minh truc tiep tren ha tang AWS.

## 3. Cach ap dung trong du an
Trong chuong trinh FCJ ([fcj-2026-curriculum](file:///Users/huylam/Downloads/aws/wiki/sources/fcj-2026-curriculum.md)), module 6 tap trung thuc hanh Bedrock. Trong giai doan dau cua du an RAG de tiet kiem chi phi, du an co the su dung LLM Provider qua API truoc khi tich hop truc tiep Bedrock Agent.
