# Tom Tat: FCAJ Workshop Template va GitHub Pages

- Nguon: [[fcaj-workshop-template-guide]]
- Tac gia / To chuc: AWS First Cloud Journey
- Ngay tiep nhan: 2026-09-18
- Chu de: Khung website Hugo Learn Theme de lam bao cao thuc tap

---

## 1. Noi dung chinh
Workshop-template la template ma nguon mo duoc xay dung tren nen tang Hugo voi giao dien `hugo-theme-learn`, duoc thiet ke chuan theo phong cach tai lieu hands-on lab cua AWS.

Template ho tro da ngon ngu song song (Anh - Viet) thong qua co che dat ten file `_index.md` va `_index.vi.md`. Cau truc cua website duoc phan cap theo cac thu muc so thu tu tuong ung voi 7 phan bao cao bat buoc cua chuong trinh.

## 2. Thong tin can chu y
- Co the dung lenh `hugo server -D` de xem truoc tren may cuc bo tai cong 1313.
- Khi build de deploy len GitHub Pages, can cau hinh dung gia tri `baseURL` trong file `config.toml` khop voi URL GitHub Pages cua ca nhan (`https://<username>.github.io/<repo>/`).
