Hướng Dẫn Kết Nối Kaggle GPU OCR Server (Qwen2.5-VL)

Khởi chạy máy chủ Vision OCR miễn phí trên Kaggle GPU (T4 x 2 / P100) và cấp quyền truy cập qua Cloudflare Tunnel

Mở Notebook Trên Kaggle Tải Tệp .ipynb
1. Thiết Lập Môi Trường Kaggle
Mở notebook trên Kaggle. Trong mục Session options ở thanh điều khiển bên phải:
  • Accelerator: Chọn GPU T4 x 2 hoặc GPU P100.
  • Internet: Bật Internet on (bắt buộc để tải thư viện và mở tunnel).
2. Thực Thi Notebook (Run All)
Bấm Run All trên Kaggle. Quá trình tự động thực hiện:
  • Cài đặt transformers, qwen-vl-utils, pycloudflared.
  • Nạp mô hình Qwen2.5-VL-7B-Instruct vào VRAM GPU.
  • Khởi chạy FastAPI (Port 8000) và mở Cloudflare Tunnel.
3. Lấy Public Tunnel URL
Tại cell cuối cùng, đợi thông báo:
URL Endpoint: https://xxx.trycloudflare.com/ocr
Sao chép chuỗi https://...trycloudflare.com.
4. Nhập Key Vào Hệ Thống
Bấm nút Nhập Endpoint Kaggle phía trên:
  • Provider: Kaggle TPU/GPU
  • Giá trị: Dán link https://...trycloudflare.com/ocr
  • Độ ưu tiên: Đặt 1 và bấm Lưu Khóa API.
