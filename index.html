Cấu Hình Block Public Access Có Kiểm Soát

Gỡ bỏ rào cản Block Public Access cục bộ theo đúng tiêu chuẩn kỹ thuật của dịch vụ Static Website Hosting, sẵn sàng tiếp nhận chính sách cấp quyền đọc công khai.

Trạng thái: Xác nhận cảnh báo bảo mật theo quy định AWS
3

Kích Hoạt Dịch Vụ Static Website Hosting

Kích hoạt tính năng Static Website Hosting với tệp chỉ mục chính là index.html, sinh ra đường dẫn Endpoint truy cập công khai không cần cấu hình cụm máy chủ web EC2 phức tạp.

Trạng thái: Hosting Type: Host a static website
4

Thực Thi Chính Sách S3 Bucket Policy (JSON)

Thiết lập tuyên bố cấp quyền s3:GetObject duy nhất cho tài nguyên bên trong bucket, tuân thủ nguyên tắc đặc quyền tối thiểu (Least Privilege) không cấp quyền ghi (PutObject) hay xóa (DeleteObject).

Trạng thái: Publicly accessible được kích hoạt

Mã Nguồn S3 Bucket Policy Đã Áp Dụng

JSON Policy

Chính sách phân quyền bảo mật cấp quyền truy cập công khai chỉ đọc (Public Read) cho mọi người dùng đối với các tài nguyên chứa trong Bucket: 

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::huylam-static-web-677994024390/*"
        }
    ]
}
